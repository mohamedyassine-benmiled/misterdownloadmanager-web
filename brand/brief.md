# Webmister README and fork identity

Mode: Read. GitHub readers need to understand the fork, see the shipped Web UI,
and start a private server without confusing upstream downloads or extension stores.
The owner chose “Webmister Download Manager”; binary names, data and protocol IDs stay compatible.

## Direction contract

**THESIS:** Documentation first: a named, attributed Web fork with real UI evidence
and one copyable Compose path, not upstream benchmark marketing repackaged as ours.

**OWN-WORLD:** Inherit GitHub's reading typography and the incumbent desktop-familiar
Web UI. A compact white W, green download arrow and deep-blue tile identify this fork.
No UI redesign, new transfer imagery or invented adoption/performance claims.

**STORY:** Recognize Webmister, understand its relationship to MDM, inspect desktop/mobile
screenshots, run Compose, enroll an owner, pair the fork extension, then find limits and source.

**FIRST VIEWPORT:** Original mark, product heading and a short fork statement; concise
download/run links, then a full-width screenshot of the shipped workspace. Setup is a
normal numbered guide below, with selectable code rather than text baked into artwork.

**FORM:** User-pinned name; GitHub-native document and existing app system. Local brand
extension, not a replacement visual world. seed: none (user-pinned surface constraints).

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review,
the verdict, DESIGN.md, and every shipping raster carrying its provenance.

Screenshots use the actual shipped HTML/CSS/JS with clearly labeled synthetic public
fixture data, never the private review instance. Releases remain prepared, not published.
